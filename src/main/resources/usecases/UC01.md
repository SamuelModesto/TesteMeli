# **Caso de Uso UC01 – Consultar Detalhes do Produto**

## **Descrição**
Como cliente, eu quero consultar um produto por id e obter detalhes desse produto.

## **Ator Principal**
- Cliente.

## **Pré-condições**
- Ter os dados do produto salvo no banco de dados.

## **Pós-condições**
- Obter resposta com status 200.
- Obter detalhes do produto no formato JSON_OUT_01.

---

## **Fluxo Principal**

* O cliente envia uma solicitação via REST passando o identificador (id)  para efetuar uma consulta de um produto especifico.

* O sistema consulta o produto na base de dados própria.

* O sistema retorna os detalhes do produto.

---

## **Fluxos Alternativos**

### **1.A – Produto Não Existe**
- **1.A.1** O usuário não possui saldo disponível (R$ 0,00).
- **1.A.2** Redirecionar para o caso de uso **UC02**.

### **2.A – Produto Sem Estoque**
- **2.A.1** O usuário possui saldo parcial do valor solicitado.
- **2.A.2** Redirecionar para o caso de uso **UC03**.


## **Entidades**
- Utilize como base para criacao das entidades os scripts de src/resources/db/migrations/*
